# pages

Static sites published with GitHub Pages at https://yookibooki.github.io/pages/.

- `chatbots/` — AI chatbot launcher, served at `/pages/chatbots/`
- `cost-calculator/` — agent cost calculator, served at `/pages/cost-calculator/`

Both are dependency-free single-page sites. No build step: push to `main` and Pages publishes the files directly.
